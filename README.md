# عود الذهب | OUD GOLD

## Premium Agarwood Electronic Cigarette Brand Website

A luxury website for a high-end Agarwood (Oud) electronic cigarette brand targeting the Middle Eastern market.

### 🌟 Features

- **Elegant Black & Gold Design**: Luxurious color scheme that represents premium quality
- **RTL Support**: Full Arabic language support with right-to-left layout
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern Animations**: 
  - Gold particle effects
  - Smooth scroll animations
  - Hover effects on products
  - Testimonial slider
- **Interactive Elements**:
  - Mobile navigation menu
  - Contact form
  - Newsletter subscription
  - Product showcase

### 📁 Project Structure


### 🚀 Getting Started

1. Simply open `index.html` in a web browser
2. No build process or dependencies required
3. All assets are loaded from CDNs

### 📱 Sections

1. **Hero**: Eye-catching landing with animated vape device
2. **Heritage**: Story of Oud tradition
3. **Products**: Showcase of three premium products
4. **Experience**: Features and video placeholder
5. **Testimonials**: Customer reviews slider
6. **Contact**: Form and contact information
7. **Footer**: Links and newsletter signup

### 🔧 Customization

To customize the website:

1. **Colors**: Edit CSS variables in `:root` section of `styles.css`
2. **Content**: Modify text in `index.html`
3. **Products**: Update product cards in the products section
4. **Images**: Replace CSS-created visuals with actual product images

### 📞 Contact Integration

The contact form currently shows an alert. To integrate with a backend:

1. Modify the form submission handler in `script.js`
2. Add your API endpoint
3. Handle form data appropriately
